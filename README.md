# Монтажи – собствен хостинг (GitHub Pages + Supabase)

Файлове: `index.html` (цялото приложение) и `supabase-setup.sql` (база данни, права, папка за снимки).

## 1. База данни и вход (Supabase)
1. Регистрирай се на supabase.com и създай нов проект (избери регион в ЕС, запази паролата за базата).
2. Отвори **SQL Editor**, залепи съдържанието на `supabase-setup.sql` и натисни **Run**.
3. В **Authentication** изключи публичната регистрация (опция от типа „Allow new users to sign up“).
4. В **Authentication → Users → Add user** създай акаунт с имейл и парола за себе си и отбележи автоматично потвърждаване (Auto Confirm). **Първият създаден потребител е админ.** След това добави и майсторите – те са със роля „Майстор“.
5. В **Project Settings → API** копирай **Project URL** и **anon public key**.

## 2. Настройка на приложението
Отвори `index.html` в текстов редактор и намери реда `SUPABASE_URL='PASTE_PROJECT_URL'`. Замени двете стойности с копираните от Supabase. (Тези две стойности са безопасни за публичен код, данните се пазят от входа.)

## 3. Публикуване в GitHub
1. Създай хранилище (repository) в GitHub и качи `index.html` (Add file → Upload files).
2. **Settings → Pages → Deploy from a branch → main → / (root) → Save.**
3. След 1–2 минути адресът е `https://ИМЕ.github.io/ИМЕ-НА-ХРАНИЛИЩЕТО/`. Отвори го на телефона и избери „Добави към началния екран“.

## Промяна на роля
Ако искаш друг човек да е админ, в SQL Editor изпълни:
`update public.profiles set role='admin' where id=(select id from auth.users where email='имейл@example.com');`

## Важно да знаеш
- Ограничението „майсторите не трият“ е само в интерфейса. Всеки вписан потребител технически може да записва в базата.
- Ако няма интернет на обекта, горе се показва „⚠ Няма връзка“ и промените се пробват да се запишат наново на всеки 5 секунди, докато страницата е отворена. Не затваряй страницата дотогава.
- Ако двама редактират едновременно, побеждава последният запис. Данните се обновяват при другите автоматично.
- Провери лимитите на безплатния план на Supabase (място, пауза при неактивност) на supabase.com/pricing.
